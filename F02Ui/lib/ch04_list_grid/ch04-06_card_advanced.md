# ch04-06: Card 심화 - 코드 설명

##  학습 목표
- 복잡한 Card 레이아웃
- 이미지와 텍스트 조합
- 여러 ListTile을 포함한 Card
- 버튼이 있는 Card

---

##  중요 코드 설명

### 1. 이미지가 있는 Card

```dart
Card(
  elevation: 4,
  child: Column(
    children: [
      Container(...), // 이미지 영역
      Padding(...),   // 내용 영역
    ],
  ),
)
```

**핵심 포인트:**
- Column으로 이미지와 내용 분리
- BorderRadius로 모서리 처리

---
