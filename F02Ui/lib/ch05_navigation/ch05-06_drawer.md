##  중요 코드 설명

### 1. Drawer 구조

```dart
Scaffold(
  drawer: Drawer(
    child: ListView(
      children: [
        DrawerHeader(...),
        ListTile(...),
      ],
    ),
  ),
)
```

**핵심 포인트:**
- `drawer`: Scaffold의 drawer 속성
- 왼쪽에서 오른쪽으로 스와이프로 열림
