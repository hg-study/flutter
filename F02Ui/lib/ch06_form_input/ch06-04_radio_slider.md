##  중요 코드 설명

### 1. RadioListTile

```dart
RadioListTile<String>(
  title: Text('옵션 1'),
  value: '옵션 1',
  groupValue: _selectedValue,
  onChanged: (value) {
    setState(() {
      _selectedValue = value!;
    });
  },
)
```

**핵심 포인트:**
- `groupValue`: 선택된 값
- 같은 `groupValue`를 공유하는 Radio는 그룹
