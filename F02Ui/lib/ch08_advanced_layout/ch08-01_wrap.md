---

##  중요 코드 설명

### 1. Wrap 기본 구조

```dart
Wrap(
  spacing: 8,
  runSpacing: 8,
  children: [...],
)
```

**핵심 포인트:**
- `spacing`: 가로 간격
- `runSpacing`: 세로 간격
- 공간 부족 시 자동 줄바꿈
