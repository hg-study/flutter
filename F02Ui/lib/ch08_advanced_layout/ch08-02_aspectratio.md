# ch08-02: AspectRatio - 코드 설명

##  학습 목표
- AspectRatio 사용법
- 가로:세로 비율 고정
- 이미지, 비디오에 적용

---

##  중요 코드 설명

### 1. AspectRatio 구조

```dart
AspectRatio(
  aspectRatio: 16 / 9,
  child: Container(...),
)
```

**핵심 포인트:**
- `aspectRatio`: 가로:세로 비율
- 16/9, 1/1, 4/3 등
