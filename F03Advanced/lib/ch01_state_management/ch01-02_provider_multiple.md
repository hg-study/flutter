##  중요 코드 설명

### 여러 상태 관리

```dart
class CounterProvider extends ChangeNotifier {
  int _count = 0;
  String _message = '안녕하세요!';
  
  int get count => _count;
  String get message => _message;
  
  void changeMessage(String newMessage) {
    _message = newMessage;
    notifyListeners();
  }
}
```

**핵심 포인트:**
- 하나의 Provider에 여러 상태 포함 가능
- 각 상태별로 Consumer 사용
