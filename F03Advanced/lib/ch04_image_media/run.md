# 실행 방법 및 결과 확인

## 사전 준비

1. **패키지 설치**
   ```bash
   cd F03Advanced
   flutter pub get
   ```

2. **권한 설정**
   - Android: AndroidManifest.xml에 권한 추가
   - iOS: Info.plist에 권한 설명 추가

3. **필요한 패키지 확인**
   - image_picker: ^1.0.7

## 빠른 실행

```bash
flutter run lib/ch04_image_media/main.dart
```

## 화면 구성

### 상단
- **AppBar**: "04단계: 이미지 & 미디어" 제목

### 본문 (스크롤 가능)
1. **갤러리에서 이미지 선택**
   - 이미지 표시 영역
   - 갤러리 선택 버튼

2. **카메라로 사진 촬영**
   - 이미지 표시 영역
   - 카메라 촬영 버튼

3. **여러 이미지 선택**
   - 가로 스크롤 이미지 목록
   - 여러 이미지 선택 버튼
   - 초기화 버튼

4. **이미지 정보 표시**
   - 경로, 이름, 크기, MIME 타입

## 확인 사항

실행 후 다음을 확인하세요:

- [ ] 갤러리에서 이미지를 선택할 수 있습니다
- [ ] 카메라로 사진을 촬영할 수 있습니다
- [ ] 여러 이미지를 선택할 수 있습니다
- [ ] 선택한 이미지가 표시됩니다
- [ ] 이미지 정보가 표시됩니다

## 문제 해결

### 문제 1: "권한 오류"

- AndroidManifest.xml에 권한 추가 확인
- iOS Info.plist에 권한 설명 추가 확인
- 실제 기기에서 테스트 (에뮬레이터는 카메라 불가)

### 문제 2: "카메라가 작동하지 않음"

- 실제 기기에서 테스트
- 에뮬레이터는 카메라 지원 안 함
- 권한 확인

### 문제 3: "이미지가 표시되지 않음"

- File 경로 확인
- 이미지 파일 존재 확인
- Image.file 위젯 사용 확인
