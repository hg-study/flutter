##  중요 코드 설명

### pubspec.yaml에 패키지 추가

```yaml
dependencies:
  http: ^1.1.2
```

**핵심 포인트:**
- `dependencies`: 의존성 섹션
- 버전 지정 (^1.1.2)
- `flutter pub get` 실행
