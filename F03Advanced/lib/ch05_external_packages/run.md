# 실행 방법 및 결과 확인

## 사전 준비

1. **패키지 설치**
   ```bash
   cd F03Advanced
   flutter pub get
   ```

2. **필요한 패키지 확인**
   - http: ^1.1.2

3. **인터넷 연결 확인**
   - API 호출을 위해 인터넷 연결 필요

## 빠른 실행

```bash
flutter run lib/ch05_external_packages/main.dart
```

## 화면 구성

### 상단
- **AppBar**: "05단계: 외부 패키지 사용" 제목

### 본문 (스크롤 가능)
1. **pubspec.yaml 패키지 추가 안내**
   - 패키지 추가 방법
   - flutter pub get 명령

2. **GET 요청 예제**
   - GET 요청 버튼
   - 응답 데이터 표시

3. **POST 요청 예제**
   - POST 요청 버튼
   - 응답 데이터 표시

4. **여러 데이터 가져오기**
   - 여러 데이터 요청 버튼
   - 목록 데이터 표시

5. **패키지 정보**
   - 사용 중인 패키지 목록
   - pub.dev 링크

## 확인 사항

실행 후 다음을 확인하세요:

- [ ] GET 요청이 작동합니다
- [ ] POST 요청이 작동합니다
- [ ] 여러 데이터를 가져올 수 있습니다
- [ ] 응답 데이터가 표시됩니다
- [ ] 로딩 상태가 표시됩니다
- [ ] 에러가 처리됩니다

## 문제 해결

### 문제 1: "http: command not found"

```bash
# pubspec.yaml에 패키지 추가 확인
# flutter pub get 실행
```

### 문제 2: "네트워크 에러"

- 인터넷 연결 확인
- API URL 확인
- 방화벽 설정 확인

### 문제 3: "JSON 파싱 에러"

- 응답 형식 확인
- json.decode 사용 확인
- 에러 처리 추가
